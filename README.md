# ⚡ AMPECO EV Charging Knowledge Base

A bilingual, searchable technical knowledge base covering the AMPECO platform, EV charging infrastructure, communication protocols, and industry terminology.

Built as an independent educational project to explore the technical concepts, systems, and standards behind modern EV charging management platforms.

### ✨ Features

- 🔎 **Instant Search** — Quickly find technical terms, protocols, and concepts across categorized reference cards.
- 🌍 **Bilingual Interface** — Switch seamlessly between English and Bulgarian.
- 🌓 **Light & Dark Modes** — Theme switching with automatic preference saving.
- 🔌 **EV Charging Protocols** — Technical references for OCPP, OCPI, OICP, and OpenADR.
- 📖 **Technical Glossary** — EV charging terminology, acronyms, and definitions.
- ⚡ **Charging Operations** — Charging sessions, MeterValues, transaction lifecycles, and troubleshooting concepts.
- 🏗️ **Platform Architecture** — CPMS, CSMS, charging infrastructure, roaming, and system integrations.
- 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- 💻 **Offline Support** — A standalone HTML application with no external dependencies.

### 🛠️ Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks, build tools, external dependencies, or installation required.

### 🚀 Getting Started

**Online:** Access the [live knowledge base](https://buba7a.github.io/AMPECO-EV-Knowledge-Base/).

**Locally:** Clone or download the repository and open `index.html` in any modern web browser.

### 🎯 Project Purpose

This project serves as a structured technical reference for understanding EV charging ecosystems, including charger-to-backend communication, interoperability standards, charging management platforms, and common operational scenarios.

It is designed to support continuous learning, technical exploration, and practical troubleshooting knowledge.
