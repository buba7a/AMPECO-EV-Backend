# ⚡ AMPECO EV Charging Cheat Sheet

A lightweight, searchable reference app covering the AMPECO EV charging ecosystem, created as a personal learning and interview preparation tool.

### Features
- 🔎 Instant search and categorized reference cards
- 🔌 EV charging protocols: OCPP, OCPI, OICP and OpenADR
- 📖 Glossary of EV charging terminology and acronyms
- ⚡ Charging sessions, MeterValues and troubleshooting concepts
- 🧠 Quick-reference notes and interview preparation material
- 💻 Responsive design with offline support

**Built with:** HTML, CSS and vanilla JavaScript. No frameworks, dependencies or installation required.

### Usage
Open `index.html` in any modern browser or access the [live app](https://buba7a.github.io/AMPECO-EV-Backend/).
